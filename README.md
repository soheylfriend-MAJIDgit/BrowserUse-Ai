# 🌐 استودیو فارسی Browser Use AI (بدون نیاز به کدنویسی)

رابط گرافیکی مدرن، فارسی و بسیار ساده برای استفاده از کتابخانه قدرتمند **[Browser Use](https://github.com/browser-use/browser-use)** با پنجره دسکتاپ **PyWebView** و لانچر یک‌کلیکی ویندوز (`start.bat`).

---

## ✨ امکانات کلیدی برنامه

- 🪟 **پنجره گرافیکی دسکتاپ با PyWebView**: ظاهر مدرن، فونت فارسی وزیرمتن (داخلی و بدون وابستگی به اینترنت) و پشتیبانی از حالت شب و روز.
- 🔑 **مدیریت چندگانه کلیدهای API و سوییچ آنی بین LLMها**:
  - پشتیبانی آماده از **۱۲ سرویس هوش مصنوعی**:
    1. **Google Gemini** (پیشنهادی • دارای سهمیه رایگان)
    2. **Groq** (اجرای فوق‌سریع مدل‌های **Llama 4** همراه با بینایی تصویر)
    3. **OpenRouter** (دسترسی به بیش از ۳۰۰ مدل مختلف با یک کلید)
    4. **Ollama** (اجرای ۱۰۰٪ لوکال مدل‌های Llama / Qwen / Gemma روی کامپیوتر شما بدون نیاز به API Key + اسکن خودکار مدل‌های نصب‌شده)
    5. **سرویس‌های واسط ایرانی و سفارشی** (دارای پیش‌فرض آماده برای **AvalAI**، **GapGPT**، **LM Studio**، **Together AI** و هر سرویس سازگار با OpenAI)
    6. **OpenAI** (GPT-4.1 / GPT-4o / GPT-5 / o4-mini)
    7. **Anthropic Claude** (Sonnet / Haiku / Opus)
    8. **DeepSeek** (V3 / R1)
    9. **Browser Use Cloud** (مدل اختصاصی Browser Use)
    10. **xAI Grok**، **Mistral (Pixtral)** و **Cerebras**
  - **سوییچ سریع یک‌کلیکی** در نوار بالای برنامه + امکان تعیین **مدل پشتیبان خودکار (Fallback LLM)** در صورت تمام شدن شارژ یا سهمیه کلید اول!
  - دکمه **«🧪 تست سلامت کلید»** قبل و بعد از ذخیره همراه با ترجمه فارسی خطاها.
- 🖥️ **مانیتور زنده مرورگر و مراحل فکر کردن هوش مصنوعی**: مشاهده زنده اسکرین‌شات صفحات، آدرس سایت، گام‌های طی‌شده، قابلیت توقف موقت (Pause)، ادامه (Resume) و ارسال دستور تکمیلی در حین کار.
- 🐍 **اجرای مستقیم کدهای پایتون (کدساز خودکار + محیط اجرا)**: تولید خودکار کد پایتونِ دستور شما و امکان اجرای مستقیم هر کد پایتون در داخل خود برنامه (یا با کشیدن و رها کردن فایل `.py` روی `start.bat`).
- 📚 **راهنمای کامل داخلی به زبان ساده**: توضیح تک‌تک بخش‌ها، مقایسه مدل‌ها و رفع خطاهای رایج در داخل خود برنامه.

## 🚀 نحوه اجرا در ویندوز (بدون هیچ کدنویسی!)

1. مطمئن شوید **Python 3.11 یا جدیدتر** (مثلاً Python 3.12) روی ویندوز شما نصب است (هنگام نصب پایتون حتماً تیک **`Add python.exe to PATH`** را بزنید).
2. کافیست روی فایل **`start.bat`** دابل‌کلیک کنید!
   - **در اجرای اول:** برنامه به صورت کاملاً خودکار محیط مجازی (`.venv`) را می‌سازد و پکیج‌های لازم را نصب می‌کند (حدود ۱ تا ۲ دقیقه).
   - **از دفعات بعد:** پنجره گرافیکی برنامه بلافاصله در چند ثانیه باز می‌شود!

### سایر فایل‌های کمکی ویندوز:
- **`start.bat`**: اجرای اصلی برنامه در پنجره دسکتاپ زیبا (PyWebView). همچنین اگر هر فایل `.py` را با ماوس بکشید و روی `start.bat` رها کنید، همان کد پایتون را برایتان اجرا می‌کند!
- **`start_web_mode.bat`**: اگر ترجیح می‌دهید برنامه داخل مرورگر وب عادی باز شود.
- **`repair_install.bat`**: در صورت قطع شدن اینترنت حین نصب اولیه یا نیاز به بروزرسانی پکیج‌ها و نصب مرورگر مستقل Chromium.

## 🔒 حریم خصوصی و امنیت کلیدهای شما

تمامی کلیدهای API، تنظیمات و تاریخچه شما **فقط به صورت محلی روی کامپیوتر خودتان** در پوشه `data/` ذخیره می‌شوند و در فایل `.gitignore` قرار دارند تا هرگز به صورت ناخواسته در گیت منتشر نشوند.
